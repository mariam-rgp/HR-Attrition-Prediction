# HR Employee Attrition Prediction

This project predicts employee attrition using Machine Learning and Deep Learning models.

## 📊 Problem
Predict whether an employee will leave the company or stay.

## 🧠 Models Used
- Logistic Regression (Cost-sensitive)
- Random Forest
- Artificial Neural Network (ANN)

## ⚙️ Steps
- Data preprocessing (encoding + scaling)
- Handling class imbalance
- Model training & evaluation
- Comparing multiple models

## 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall (most important)
- F1-score

## 🏆 Best Insight
Logistic Regression achieved the best recall for detecting employees likely to leave.

## 🛠 Tools
Python, Pandas, Scikit-learn, TensorFlow, Matplotlib, Seaborn
